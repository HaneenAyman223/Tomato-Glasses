# Tomato Glasses Middle East: home page concept

Static home page redesign concept (single `index.html`, no build step).

- Mobile-first, tested layouts for phones, tablets and desktop
- Right-to-left ready (logical CSS properties) for a future Arabic version
- Product photos and links point to the live store at tomatoglasses.me
- `noindex` is set, so search engines will not list this concept page

## Publish with GitHub Pages
1. Push this folder to a GitHub repository.
2. Repository Settings, then Pages.
3. Source: Deploy from a branch. Branch: `main`, folder: `/ (root)`. Save.
4. The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.
